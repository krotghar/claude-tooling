Результат ревью — вход для решения пользователя. По умолчанию: прогнал ревью → показал
находки → жду, что из этого брать. Правки по замечаниям сам не применяю, даже если
замечание очевидно верное и касается кода, который я же написал.

**Why:** ревью заказывают, чтобы решать самому, а не чтобы агент расширил диф ещё на
итерацию. Граница — не авторство строк, а то, что ревью уже отдано пользователю.

**How to apply:** отчёт по ревью заканчивать списком «что предлагаю сделать» по замечаниям
и ждать. Если в том же сообщении сказали «прогони ревью и почини» — чинить можно.
