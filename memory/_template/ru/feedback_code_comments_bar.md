Комментариев в коде по умолчанию не писать. Комментарий оправдан, только когда без него
компетентный читатель действительно не разберётся: неочевидный обход бага, внешнее
ограничение, причина, которой нет в коде. «Полезно знать», «тут неочевидный порядок»,
пересказ кода — не проходят.

**Why:** комментарий, который пересказывает код, стареет, расходится с ним и создаёт
впечатление, что строка сложнее, чем она есть. Защитой от регресса он не работает.

**How to apply:** прежде чем написать комментарий, проверить, что без него читатель именно
не разберётся. Одобрение ревьюера-субагента планку не подтверждает. Язык комментария — по
конвенции проекта. Связано с [[feedback-no-explanatory-comments-in-review]].
