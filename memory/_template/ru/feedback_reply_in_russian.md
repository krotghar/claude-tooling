Всё, что видит пользователь, писать по-русски с первого сообщения: статусы, сводки планов,
вопросы, итоги. Технические идентификаторы (классы, файлы, задачи сборки) не переводить.

**Why:** англоязычный отчёт приходится мысленно переводить, чтобы свериться с постановкой.

**How to apply:** размышления и задания субагентам — на любом языке; их результат
пересказывать пользователю по-русски.
