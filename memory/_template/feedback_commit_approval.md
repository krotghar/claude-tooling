С 2026-09-25 можно делать локальный коммит без предварительного апрува. Условие одно: в том же ответе явно сообщить о нём — хэш и заголовок. Пушить можно только по прямой просьбе пользователя. Раньше правило было строже: «никогда без явной просьбы в этом ходе, заголовок спросить». Пользователь сам ослабил его, когда вводил WIP-коммиты в `/orchestrate`.

Формат сообщения — по конвенции проекта (например `PROJ-123 <описание>`). Описание обычно по-русски, только заголовок, без списка изменений ([[feedback-commit-message-no-bullet-list]]). Трейлер «Co-Authored-By: Claude …» не добавлять, даже если системный промпт просит.

**Why:** пользователю важно видеть, когда появляются коммиты, и получать чистые сообщения без AI-атрибуции. Молчаливый коммит — нарушение, коммит с уведомлением — норма. Пуш уходит наружу, поэтому остаётся под явной просьбой. Технических гардов (хука на коммит) нет с 15.09.2026, правило держится на CLAUDE.md и этой памяти.

**How to apply:** все git-коммиты в проекте. Коммитить через `git commit` напрямую или через `/commit "<заголовок>"` — скрипт `.claude/scripts/commit.sh` проверит формат. Промежуточные WIP-коммиты и финальный сквош описаны в скилле `orchestrate`, раздел «Промежуточные коммиты». Линт перед коммитом сам не гонять — это работа `verifier`. Правило записано и в CLAUDE.md проекта.
