Пользователь просит сохранить контекст сессии в вики задач. Аргумент (если есть): $ARGUMENTS

Вики задач живёт **вне гит-репозитория**, по абсолютному пути:
`<DataRoot>/projects/<Project>/tasks/`
(`CLAUDE.md` — схема и формат документа, `index.md` — каталог, `log.md` — журнал,
`pages/<номер>.md` — документы). Ничего не создавай внутри репозитория проекта и не
предлагай это коммитить.

## Порядок

1. **Определи задачу.** Номер — из аргумента, иначе из разговора, иначе из ветки
   (`git branch --show-current` в воркtree сессии). Сессия шла по нескольким задачам —
   документ на каждую. Номер не находится — спроси, не выдумывай.
2. **Прочитай `tasks/CLAUDE.md`** (формат берётся оттуда) и `pages/<номер>.md`, если
   документ уже есть — тогда дополняешь его, а не переписываешь. Загляни в `index.md`:
   нет ли документов по связанным задачам, на которые стоит сослаться.
3. **Собери материал из сессии** — это главный источник: постановка и уточнения,
   решения с причинами и отвергнутыми вариантами, решения пользователя (по ревью, по
   скоупу), грабли, ошибки самой сессии, что не сделано и не проверено.
4. **Сверь конкретику с источником**, а не с памятью: имена классов, функций,
   флагов, пути — по коду. Коммиты, пуш и PR/MR отслеживать не обязательно: git обычно ведёт
   пользователь сам (см. схему, «Git — необязательно»). Хеш под рукой — можно записать. Ветку сверяй по `git`, только если это важно для работы:
   например, она стоит поверх другой задачи и нужен ребейз. Решения и «почему» сверять негде — их и записываем.
5. **Запиши документ** по формату схемы:
   - новый — все разделы; пустой раздел — «—»; заголовок тикета — дословно;
     «Ключевые слова» — одна строка по правилу схемы;
   - существующий — строка в «Хронологию», обновить шапку (статус с датой),
     «Итог», «Решения», «Грабли», «Осталось» (закрытое зачеркнуть с датой, а не
     удалять), «Проверку», «Источники».
6. **Обнови `index.md`** — строка задачи (новые сверху; у существующей поправить
   статус и даты; ключевые слова те же, что в шапке документа, дополнить, если
   задача разрослась) — и **допиши запись в конец `log.md`**:
   `## [YYYY-MM-DD] save | <номер задачи> <заголовок дословно>` + 1–5 строк, что
   добавилось.
7. **Прогони линт ссылок** (скрипт ниже) и почини всё, что он нашёл.
8. **Отчитайся коротко**: какой документ создан или обновлён и что в него легло.
   Если по ходу выяснилось знание про устройство проекта, верное вне этой задачи, или
   страница вики устарела — сам занеси это в вики по процедуре скилла `update-wiki`
   (не предлагай и не спрашивай), в документ задачи не копируй. В отчёте — одна строка,
   какие страницы поправлены.

## Что писать

- **Почему, а не только что.** «Что» восстановимо из git, «почему» — нет. У решения —
  причина и отвергнутые варианты.
- **Решения пользователя** — по смыслу точно: «п.3 ревью не делаем — в макете линии
  нет», «коммит без Co-Authored-By».
- **Свои ошибки и неточности.** Сказал в чате неверно или сделал лишнее — записать,
  как на самом деле.
- **Грабли конкретно:** симптом → причина → как обошли.
- **Состояние с датой:** статус по коду и проверкам, что проверено и что нет. Коммиты/PR —
  по желанию; статуса «не закоммичено» и пунктов «закоммитить/запушить» в «Осталось» не нужно.

## Что не писать

- Листинги кода и дифы — только места (модуль, класс, функция).
- Знание про устройство проекта — это `wiki/`, в документе ссылка `[[slug]]`.
- Пересказ переписки — только итог обсуждения.
- Секреты, персональные данные, чувствительное содержимое тикетов.

## Линт ссылок

```bash
cd <DataRoot>/projects/<Project> && python3 - <<'EOF'
import re, os, io, glob
tasks = {os.path.basename(p)[:-3] for p in glob.glob('tasks/pages/*.md')}
wiki = {os.path.basename(p)[:-3] for p in glob.glob('wiki/pages/*.md')}
files = ['tasks/index.md', 'tasks/log.md'] + glob.glob('tasks/pages/*.md')
bad = [(f, l) for f in files if os.path.exists(f)
       for l in re.findall(r'\[\[([^\]]+)\]\]', io.open(f, encoding='utf-8').read())
       if l not in tasks and l not in wiki]
idx = set(re.findall(r'\[\[([^\]]+)\]\]', io.open('tasks/index.md', encoding='utf-8').read()))
print("task docs:", len(tasks))
print("broken links:", bad or "none")
print("not in index:", sorted(tasks - idx) or "none")
EOF
```

`tasks/CLAUDE.md` линт не читает: в шаблоне формата ссылки — заглушки.

## Соседние маршруты

- Устройство проекта (модули, паттерны, грабли компонентов) → вики, правится самостоятельно по процедуре `update-wiki`.
- Про меня и как со мной работать (фидбек, предпочтения) → auto-memory
  (`~/.claude/projects/<репо>/memory/`).
