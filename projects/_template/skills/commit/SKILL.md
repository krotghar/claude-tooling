Пользователь явно попросил закоммитить с заголовком: $ARGUMENTS

Выполни ровно один шаг — вызови скрипт-обёртку, передав заголовок как единственный аргумент:

```
${CLAUDE_PROJECT_DIR}/.claude/scripts/commit.sh "$ARGUMENTS"
```

Скрипт сам проверит формат (заголовок в одну строку, без списка изменений, без `Co-Authored-By`) и либо создаст коммит, либо откажет с понятной причиной — в этом случае покажи причину пользователю и не пытайся коммитить в обход скрипта.

В рамках этого скилла не вызывай `git commit` напрямую — только через этот скрипт. Префикс задачи (`PROJ-123 ...`) скрипт не проверяет: это конвенция из `CLAUDE.md` проекта, жёсткая проверка при желании дописывается в `.claude/scripts/commit.sh`.
