# name-session-hook — имя сессии по номеру задачи

| | |
|---|---|
| Где | `home/scripts/name-session-hook.sh` в тулинге → `~/.claude/scripts/name-session-hook.sh` + хук `UserPromptSubmit` в живом `~/.claude/settings.json` \
| Переезд | 2026-11-19 — из данных в тулинг сразу после заведения, по общей политике (скрипты машинного уровня — в git тулинга) |
| Сейчас | POSIX sh + jq, подключён в home settings; срабатывает не чаще первого промпта сессии — на 2026-11-19 |
| Связано | [[statusline]] (показывает `session_name`), [[session-start-hooks]] |

## Зачем заведено
Просьба пользователя 2026-11-19: в начале каждой сессии имя сессии должно быть
либо номером задачи, если он передан в первом промпте, либо кратким
AI-нзванием по контексту промпта. Имя попадает в статус-бар (`session_name`
в stdin статус-лайна) и в пикер `/resume`.

## Решения
1. **2026-11-19 — хук `UserPromptSubmit`, не SessionStart и не скилл.**
   `SessionStart` не видит первый промпт (номер из него не вытащить), модель не
   может вызвать встроенный `/rename`, скилл уместен только для вызываемых
   моделью действий. `UserPromptSubmit` получил поле вывода `sessionTitle`
   («name sessions automatically based on the prompt content»). Источник:
   hooks reference, https://code.claude.com/docs/en/hooks.md, 2026-11-19.
2. **2026-11-19 — только номер задачи; AI-название не дублируем.** AI-заголовок
   по первому промпту Claude Code генерирует сам фоновым запросом к маленькой
   модели, когда кастомного имени нет (sessions reference, `--name`/`/rename`).
   Поэтому хук промолчал → работает нативная генерация: дублировать её в хуке
   не нужно. Отвергнуто: запрос к модели из хука, парсинг транскрипта.
3. **2026-11-19 — «первый промпт» определяется по транскрипту: есть
   `"type":"assistant"` — сессия уже идёт, хук молчит.** Иначе поздние промпты
   со ссылками на тикеты («сделай по ONX-456») переименовывали бы сессию.
   Нет `transcript_path` или файла — считаем первым (безопасный fallback).
4. **2026-11-19 — паттерны номера: `PREFIX-123` (2+ лат. буквы/цифры до тире) в
   любой части первой строки, регистр не важен; голое число 1–6 цифр — только
   если это самый первый токен сообщения.** Голое число выступает как
   металл-запись «123» из правил пользователя про `PROJ-123` и «123»; ведущее
   число о通俗易懂 и «сделай 3 правки» не ловится. Имя приводится в верхний
   регистр (`PROJ-123`).

## Пробелы и открытые вопросы
- Кастомное имя, заданное вручную (`claude -n`/`/rename`), хук проверить не
  может: в stdin `UserPromptSubmit` нет `session_title` (он есть у
  `SessionStart`). Если первый промпт содержит номер тикета, хук перезапишет
  ручное имя. Поднято 2026-11-19; если заметно мешает — добавить проверку
  через SessionStart: ставить флаг.
- «Задача по номеру» читается из вики задач по документу, но имя сессии —
  только номер, без префикса проекта. Если номера совпадают между проектами,
  различай в пикере по cwd/бранчу, не менять.
