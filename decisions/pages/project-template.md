# Шаблон проекта: projects/_template, memory/_template, link.sh --init

| | |
|---|---|
| Где | `projects/_template/`, `memory/_template/`, `link.sh` (`--init`, пропуск `_*`) |
| Сейчас | Стек-нейтральный набор. Скиллы: `orchestrate`, `check`, `diff-review`, `commit`, `save-task-context`, `update-wiki`, `unit-tests`. Агенты: `verifier`, `regression-checker`, `bug-investigator`, `reviewer`. Скрипты: `wiki_index.sh`, `research_edit_guard.sh`, `commit.sh`. Заготовки: `CLAUDE.md`, `settings.json`, `wiki-CLAUDE.md`, `tasks-CLAUDE.md`. Плюс 12 общих feedback-памятей. Новый проект получает **копию** через `link.sh --init` (на 2026-10-28) |
| Связано | [[tooling-data-layout]], [[knowledge-routing]] |

## Зачем заведено

Чтобы каждый новый проект получал базовый нейтральный набор скиллов и агентов, не
портировал его руками и не стартовал пустым. Шаблон должен годиться для публичного
репозитория.

## Решения

1. **2026-10-28 — шаблонная модель: копия, а не симлинк.** Проект специализирует свою
   копию; находки, которые годятся всем, поднимаются в шаблон отдельной работой.
   Отвергнуто: симлинк на шаблон — тогда проект не может поменять файл, не затронув
   остальных.
2. **2026-10-28 — шаблон стек-нейтральный.** Сборка, тесты, линт и запуск во всех агентах
   и скиллах берутся из раздела Commands в `CLAUDE.md` проекта; нет команды — агент
   докладывает, а не выдумывает. Проверка поведения — запуском приложения или CLI по
   `CLAUDE.md`. Ревьюер общий, правила под стек дописываются в проекте.
3. **2026-10-28 — что не обезличивается:** всё написано по-русски; в `commit` заложен
   формат коммита автора (заголовок одной строкой, без списка, без `Co-Authored-By`).
4. **2026-10-28 — `memory/_template`: 12 общих feedback-памятей,** без привязки к стеку и
   командному процессу.
5. **2026-10-28 — `link.sh --init <воркtree>`.** Нет обвязки проекта в данных — копирует
   шаблон, раскладывает `wiki/` и `tasks/` с заготовками `index.md`/`log.md`, подставляет
   `<Project>`, пишет дату копии в `.template-origin`, линкует. `memory/_template` не
   копируется (делается руками). Без `--init` отсутствие обвязки — ошибка с подсказкой.
6. **2026-10-28 — плейсхолдеры путей `<DataRoot>`, `<ToolingRoot>`** вместо зашитого пути
   данных; подставляет `--init`. См. [[tooling-data-layout]] п. 2.
7. **2026-10-28 — research-воркtree агентов-исследователей — от главного воркtree** (первая
   строка `git worktree list`), под `research_edit_guard.sh`. Отвергнуто: расширять хук на
   любой `*-research-*` — ослабило бы гард.
8. **2026-10-28 — отложено: скилл `/harvest` и регулярный агент,** собирающие находки из
   проектов в шаблон. Вернуться, когда на шаблоне будет 2–3 проекта.
